# 棋局助手 MVP

这是一个验证“游戏状态 + 用户画像 + 端侧大模型”的 Android 示例。当前棋盘是轻量占位实现，重点验证上层应用如何像调用云端 API 一样调用本地模型。

## 使用流程

1. 首页下载并启用一个已安装模型。设备会按可用内存、温度和历史基准自动选择模型；异常时降级到更小模型。
2. 点击“打开棋局助手 MVP”。
3. 在棋盘上连续点击两个格子记录走法，填写玩家风格/目标。
4. 点击“分析下一步”获得建议和情绪鼓励，或点击“复盘讲故事”获得故事化复盘与两条训练建议。

## 当前分级建议

| 设备档位 | 默认模型 | 说明 |
| --- | --- | --- |
| 低端/高温/内存紧张 | Qwen2.5 0.5B | 优先保证响应和稳定性 |
| 中端 | Qwen2.5 1.5B | 更好的复盘和个性化表达 |
| 高端且通过基准 | Qwen2.5 3B | 质量优先，首 token 延迟较高 |

应用应在每次生成前检查温度、可用内存和模型状态；取消生成后释放请求并回收模型资源。任何加载或 native 错误都应自动切换到下一档模型。
